## Project E - SH1015

Våran handlerade använde [<u>QFitsView</u>](https://www.mpe.mpg.de/~ott/QFitsView/) för att inspektera datan.


## Kör koden
För att köra koden behöver du `numpy`, `astropy`, `matplotlib`. Du kan ladda ner dessa genom att köra följande kommando:

```
python -m pip install numpy matplotlib astropy
```

## Ellipsanpassning
För att köra `ellipse.ipynb` krävs `cv2`. Du kan ladda ner detta genom att köra följande kommando:

```
pip install opencv-python
```

Om det inte fungerar måste du lägga till python som [<u>miljövariabel</u>](https://chatgpt.com/).
